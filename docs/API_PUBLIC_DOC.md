# 🌐 Public API Documentation
توثيق شامل لجميع نقاط الوصول العامة في نظام **Shahm Law Firm**  
كل هذه الـ endpoints لا تحتاج تسجيل دخول (إلا إذا وُضّح غير ذلك).

---

## 🏠 1. Home API
### **GET /api/public/home/**
تعيد جميع البيانات الأساسية للصفحة الرئيسية:

- الهيرو الأساسي
- الهيرو الثانوي
- الأعمدة والروابط الخاصة بالفوتر
- آخر الخدمات الفعالة
- آخر المقالات المنشورة (3 فقط)
- كل أعضاء الفريق الفعّالين
- إعدادات الموقع العامة
- إعدادات الـ SEO الافتراضية

#### ✔️ Response Example
```json
{
  "hero_main": {...},
  "hero_secondary": {...},
  "footer": [...],
  "services_home": [...],
  "blog_latest": [...],
  "team": [...],
  "site_settings": {...},
  "seo": {...}
}
